# Category map

Use the narrowest primary category. Tags can express secondary capabilities.

| Category | Include | Exclude |
| --- | --- | --- |
| `core` | IINA itself, official site, authoritative core references | Community plugins |
| `official-plugin` | Plugins maintained in the IINA organization | Merely listed community plugins |
| `playback` | Seeking, looping, speed, playlists, browsing, resume | Capture-only tools |
| `subtitles-language` | Subtitle search, rendering workflows, translation, dictionaries, danmaku | General media libraries |
| `libraries-streaming` | Jellyfin, online media, catalog and service browsing | Tracking-only integrations |
| `capture-editing` | Clips, screenshots, recording, frame/timecode tools | Playback shaders |
| `enhancement-rendering` | Upscaling, shaders, HDR, VR conversion, audio/video processing | General FFmpeg tooling |
| `casting-integrations` | AirPlay, Chromecast, Home Assistant, target devices | Browser handoff |
| `tracking-scrobbling` | Trakt, AniList, MyShows, ListenBrainz, progress sync | Local resume state |
| `automation-companions` | Browser handoff, file actions, shortcuts, companion workflows | Plugin SDK resources |
| `development` | Templates, API types, build tools, developer examples | End-user plugins |
| `media-tooling` | mpv, FFmpeg, MKVToolNix, MediaInfo, rendering libraries | IINA-specific plugins |
| `historical` | Archived or superseded projects retained for context | Unsupported projects with no research value |
