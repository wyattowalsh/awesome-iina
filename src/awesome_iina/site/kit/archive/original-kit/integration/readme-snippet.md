# README hero snippet

Copy the selected export to `assets/brand/readme-hero.png` in the repository, then
adapt this snippet. Keep a real text heading and description near the image.

```html
<p align="center">
  <img
    src="assets/brand/readme-hero.png"
    alt="Awesome IINA — plugins, playback, discovery, and media workflows for IINA"
    width="1200"
  />
</p>
```

Set the GitHub social-preview image separately in repository Settings. This README
image does not configure it. Avoid making essential project information available
only inside the raster banner.
