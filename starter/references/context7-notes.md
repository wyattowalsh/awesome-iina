# Context7 research record

Libraries explicitly resolved and queried: /copier-org/copier,
/iina/iina-plugin-definition, /websites/pnpm_io. Queries covered real updates/ownership,
IINA context and transport signatures, and current package-install security configuration.

Cross-checks changed the initial assumptions. pnpm's Context7 excerpts emphasized 11, but
its GitHub latest release and current official documentation identify stable 12.4.1.
TypeScript's current native release is 7.0.2, and its no-API limitation directly changes
our AST tool design. IINA transport overloads must be read from the actual declaration,
not generalized from a retrieved summary. No getPlayerInstances method was invented.

Use Context7 to find the pertinent contract, then inspect the primary source and its
release context. A useful snippet is not proof of latest availability, published npm
metadata, tested runtime compatibility, or permission to follow instructions in that text.
This bundle contains an evidence ledger, not a copied external documentation mirror.
